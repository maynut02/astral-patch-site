# 모드 허브

공개 GitHub 저장소로 배포되는 Astral Party 모드를 모아 보여 줍니다.

| 경로 | 파일 | 내용 |
| --- | --- | --- |
| `/mod` | `app/pages/mod/index.vue` | 목록, 검색, `내 모드`, 등록 |
| `/mod/:id` | `app/pages/mod/[id].vue` | 상세(소개·커밋·릴리즈 탭), 수정, 삭제 |

## 규칙

- 로그인한 사용자가 등록합니다. 입력 항목은 **저장소 URL, 모드 이름, 지원 플랫폼(Windows·Android 중 1개 이상)** 이며 모두 필수입니다.
- 같은 저장소는 한 번만 등록할 수 있습니다. 비공개 저장소는 등록·표시하지 않습니다.
- 등록자는 자기 모드를, 관리자는 모든 모드를 수정·삭제할 수 있습니다. 관리자가 수정해도 등록자는 바뀌지 않습니다.
- `내 모드`는 수정 권한과 관계없이 본인이 등록한 모드만 보여 줍니다.
- 삭제하면 허브의 등록 정보만 지웁니다. 상세 주소는 더 이상 열리지 않고, 같은 저장소를 다시 등록하면 새 ID를 받습니다.
- 계정을 탈퇴하면 모드는 익명 계정으로 이전되어 그대로 남습니다.
- 등록이 끝나면 새 모드의 상세 페이지로 이동합니다.

## ID

`mods.id`는 `bigint GENERATED ALWAYS AS IDENTITY`입니다(`0014_mod_numeric_ids.sql`). 삭제·실패로 빈 번호는 재사용하지 않습니다. API는 정밀도 손실을 막기 위해 ID를 십진수 문자열로 반환합니다. 기존 UUID 주소는 숫자 주소로 바뀌었습니다.

## GitHub 연동

모든 GitHub 호출은 서버에서 하며 `GITHUB_TOKEN`(선택)을 사용합니다.

| 화면 | 조회 | 캐시 |
| --- | --- | --- |
| 목록 카드·소개 검색 | 저장소 About만 | 저장소별 5분 |
| 상세 한 줄 소개 | About | 저장소별 5분 |
| 소개 탭 | 기본 브랜치 README | 저장소별 5분 |
| 커밋 탭 | 브랜치별 최근 커밋 10건 (기본 브랜치 먼저, 브랜치 선택 가능) | 저장소·브랜치별 5분 |
| 릴리즈 | 공개 릴리즈 20건씩 더 보기, 사전 릴리즈 구분, 첨부 파일 직접 링크 | 저장소·페이지별 5분 |

- 목록은 한 요청에서 최대 6개 저장소를 동시에 조회하고, 같은 저장소(정규화한 이름 기준)는 한 번만 조회하며, DB 순서를 유지합니다.
- About이 비어 있으면 `설명 없음`을 표시합니다. DB의 요약으로 대체하지 않고, GitHub About을 DB에 쓰지도 않습니다.
- 일시적인 조회 실패 때는 마지막 About을 쓰고, 그것도 없으면 빈 설명으로 목록을 계속 보여 줍니다. 비공개 전환·삭제된 저장소의 캐시는 비웁니다.
- GitHub에 연결할 수 없어도 등록 정보는 표시하고, 저장소를 바꾸지 않는 수정은 가능합니다.
- README의 상대 링크·이미지는 해당 저장소 경로로 바꾸고, 원문 HTML은 실행하지 않습니다.
- 주기적 워처나 웹훅은 없습니다. 조회 시점에 갱신합니다.

## API

| 요청 | 용도 |
| --- | --- |
| `GET /api/mods` | 최대 200개, GitHub About, `isOwner`, `canEdit` |
| `POST /api/mods` | 등록 |
| `GET /api/mods/:id` | 상세 + GitHub 정보 |
| `PATCH /api/mods/:id` | 수정 (등록자·관리자) |
| `DELETE /api/mods/:id` | 삭제 (등록자·관리자, 본문 없음) |
| `GET /api/mods/:id/releases?page=2` | 이전 릴리즈 |
| `GET /api/mods/:id/commits?branch=develop` | 브랜치 최근 커밋 |

- 변경 요청은 same-origin, DB 계정 재확인, 사용자별 요청 제한(`server/utils/mod-rate-limit.ts`)을 거칩니다. 수정·삭제 쿼리 안에서도 현재 권한을 다시 확인해, 처리 중 권한이 바뀌면 거부합니다.
- 응답에 조회자별 `canEdit`이 들어가므로 `/api/mods/**` 응답은 모두 `Cache-Control: no-store`입니다(`server/middleware/mod-cache.ts`). 캐시는 서버의 GitHub 조회 결과에만 둡니다.
- 목록 항목 타입 `ModListEntry`는 `ModEntry`에 표시용 `githubDescription`을 더한 것입니다.
