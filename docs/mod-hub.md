# 모드 허브 초안

`/mod`에서 누구나 모드를 검색하고 상세정보를 확인할 수 있습니다. 상세 주소는 `/mod?mod=<UUID>`입니다.

로그인한 사용자가 공개 GitHub 저장소를 등록합니다. 등록자만 이름, 소개, 상세정보(Markdown), 지원 플랫폼, 연결 저장소를 수정할 수 있습니다. 관리자도 다른 사용자의 모드 정보를 수정할 수 없습니다. 같은 저장소는 중복 등록할 수 없습니다.

## DB 준비

기존 migration 실행 절차로 `database/migrations/0013_mod_hub.sql`을 적용해야 등록·조회가 동작합니다. 웹 서버는 테이블을 자동 생성하지 않습니다. 계정을 탈퇴하면 모드는 익명 계정으로 이전되어 설명과 다운로드 링크가 유지됩니다.

## GitHub 연동

- 기본 브랜치의 README와 최근 커밋 10건을 표시합니다.
- 공개 릴리즈를 20건씩 불러오고 이전 버전을 더 불러올 수 있습니다. 사전 릴리즈는 별도로 표시합니다.
- 파일 다운로드는 GitHub 릴리즈의 첨부 파일로 직접 연결합니다. 첨부 파일이 없는 릴리즈도 표시합니다.
- README의 상대 링크와 이미지는 해당 저장소의 경로로 연결합니다. 원문 HTML은 실행하지 않습니다.
- 상세 화면 조회 시 GitHub를 확인하고 저장소별 정보를 5분 캐시합니다. 별도의 주기적 워처나 웹훅은 아직 없습니다.
- `GITHUB_TOKEN`은 선택 사항이며 기존 릴리즈 연동과 공유합니다. 서버에서만 사용하고 비공개 저장소는 등록·표시하지 않습니다.
- GitHub에 연결할 수 없어도 등록된 상세정보를 표시하며, 연결 저장소를 변경하지 않는 정보 수정은 가능합니다.

## API

| 요청 | 용도 |
| --- | --- |
| `GET /api/mods` | 최근 등록·수정된 모드 최대 200개, 조회자의 수정 가능 여부 |
| `POST /api/mods` | 로그인한 사용자의 모드 등록 |
| `GET /api/mods/:id` | 모드 상세정보와 GitHub 정보 |
| `PATCH /api/mods/:id` | 등록자의 정보 수정 |
| `GET /api/mods/:id/releases?page=2` | 이전 릴리즈 조회 |

변경 요청에는 기존 same-origin·JSON 검사, DB의 최신 로그인 정보 검사, 사용자별 요청 제한을 적용합니다. 수정 쿼리도 등록자 ID를 조건으로 사용합니다.

## 검증

```sh
pnpm test:mods
pnpm check
```

후속 개선 후보는 목록 서버 페이지네이션, 태그·카테고리, 설치 환경별 파일 분류, GitHub 변경 알림입니다.
